SwinX License
===============================================================================

SwinX is a Windows API compatibility layer that runs on Linux and macOS. Its
goal is to help projects developed for the Windows platform achieve cross
-platform support; the near-term goal is primarily to support cross-platform
development for the open-source soui4 project.

Free for non-commercial use; commercial use is paid, and the fee is set by
contacting the author.

Please comply with the following terms when using SwinX:

   the corresponding third-party licenses; third-party code is not converted to
