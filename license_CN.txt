swinx License
===============================================================================

swinx 是一套运行在 Linux 及 macOS 上的 Windows API 兼容层，目标在于帮助为 Windows
平台开发的项目实现跨平台支持，前期目标主要是为 soui4 开源项目支持跨平台设计。
